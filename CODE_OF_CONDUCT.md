# Code of Conduct

## Our promise

We want this project to be welcoming, respectful, and useful for everyone,
especially people who are new to AWS or open source.

## Expected behavior

- Be respectful and patient.
- Welcome questions and beginner-friendly explanations.
- Give helpful, specific feedback.
- Credit other people's work and ideas.
- Focus on the project, not on personal criticism.

## Unacceptable behavior

- Harassment, insults, discrimination, or personal attacks.
- Trolling, threats, or deliberately disruptive behavior.
- Sharing private information without permission.
- Posting passwords, access keys, MFA codes, or other secrets.
- Any behavior that would be unsafe or illegal.

## Reporting a concern

Please open a GitHub issue with the label `conduct` when possible. For
sensitive concerns, contact the repository maintainers privately through
GitHub instead of posting personal details publicly.

Reports will be reviewed fairly and kept as confidential as possible. We may
remove content, close discussions, or restrict participation when necessary to
protect the community.

## Scope

This code of conduct applies to this repository, its issues, pull requests,
discussions, and other project spaces.
